# Портфолио Станислава Постникова

Сайт-визитка Senior Frontend-разработчика. Три страницы — три времени суток: «Обо мне» (звёздная
ночь с семью планетами и северным сиянием), «Опыт» (рассвет в тумане), «Контакты» (день). Фон — пиксельный
пейзаж с параллаксом, кострами, ручьём, теремом, мельницей и кометами. В нём живут звери: ночью сова,
летучие мыши и стая, которая воет на Луну; на рассвете ёжик в тумане, петух, журавли и стадо с пастухом;
днём коровы на лугу, пчёлы у пасеки, бабочки и голубь, который носит письма в Telegram. Сверху падает то,
что положено по календарю: листья, снег, лепестки или тополиный пух (`?season=winter` — посмотреть другое время
года). По сайту спрятаны 40 ачивок, из них 18 секретных.

«Обо мне» — витрина: на ней сразу лента опыта, «Коротко для HR» и контакты, чтобы рекрутеру хватило
одной страницы. Остальные вкладки — подробности. Строки ленты ведут к нужной главе на «Опыте».

## Как открыть

```bash
npm install
npm run build
```

Затем откройте **`out/index.html`** двойным кликом — сервер не нужен. Эта же папка `out/` целиком
выкладывается на любой статический хостинг (GitHub Pages, Vercel, Netlify, Яндекс Облако).

Сайт живёт на https://mirudistok32.github.io/portfolio/. Каждый пуш в `master` проверяет (`npm run check`), пересобирает и
публикует его через GitHub Actions (`.github/workflows/deploy.yml`, в настройках Pages источник — «GitHub Actions»).

Для разработки с горячей перезагрузкой: `npm run dev` и http://localhost:3000.

## Команды

```bash
npm run dev            # разработка
npm run build          # сборка в out/ + подготовка к открытию с диска
npm run preview        # посмотреть out/ через локальный сервер
npm run typecheck      # TypeScript
npm run lint           # ESLint (правила Next.js + сортировка импортов)
npm run contrast       # проверка контраста текста по WCAG AA
npm run test           # юнит-тесты (Vitest): ачивки и хранилища
npm run shots          # снимки out/ в .screenshots/: 3 вкладки × 4 времени года × 390/1280
npm run format         # Prettier
npm run check          # всё сразу: типы, линтер, контраст, формат, юнит-тесты
npm run check:full     # check + сборка и e2e (Playwright по file://, 390 px и ноутбук)
```

## Стек

- **Next.js 16** (App Router, статический экспорт) + **React 19** + **TypeScript**
- Обычный CSS с токенами в `src/app/globals.css`
- Состояние — маленькие внешние хранилища на `useSyncExternalStore` (`src/lib/store.ts`), прогресс ачивок — в `localStorage`
- Пейзаж — `canvas` без библиотек (`src/components/scene/`)

## Где что лежит

```
src/
  app/            layout (SEO-метаданные, шрифты), page, sitemap, robots, иконка, стили
  content/        profile.ts — ВСЕ тексты сайта: опыт, заклинания, контакты, профиль для HR
  components/     Shell (вкладки и время суток), страницы, часы, ачивки, XP-шкала, медальон
    scene/        draw.ts — статичные слои пейзажа, engine.ts — анимация и тайники, fauna.ts — звери
  lib/            хранилища, ачивки, тосты, копирование, эффекты
tests/unit/        юнит-тесты логики (ачивки, хранилища)
tests/e2e/         e2e по out/index.html с диска
scripts/
  prepare-static.mjs  пост-обработка out/ (см. ниже)
  contrast.mjs        проверка контраста
  shots.mjs           скриншоты и проверка консоли и прокрутки
public/           og.png (превью для соцсетей), llms.txt (сводка для ИИ-ассистентов рекрутеров)
```

Чтобы поменять текст, правьте `src/content/profile.ts`. Адрес сайта для canonical, sitemap и Open Graph —
`SITE.url` там же. Резюме: положите PDF в `public/cv.pdf` и впишите `cv: 'cv.pdf'` в `SITE`.

## Почему открывается с диска

`scripts/prepare-static.mjs` после сборки:

1. делает все пути относительными (`./_next/…`), включая данные React и рантайм Turbopack;
2. кладёт шрифты в `_next/static/fonts-offline.css` в виде data-URI: с `file://` Chrome не отдаёт
   шрифты по CORS. Этот файл подключается только при открытии с диска, на хостинге шрифты грузятся обычно;
3. подключает скрипты React сразу после первой отрисовки: весь текст и фото уже есть в HTML, поэтому
   страница появляется мгновенно, а интерактивность догружается следом.

## SEO

- Весь текст всех трёх страниц есть в статическом HTML (вкладки только скрывают лишнее).
- `title`, `description`, canonical, Open Graph (`og.png`), Twitter Card, `robots`, `sitemap.xml`, `robots.txt`.
- Микроразметка Schema.org: `ProfilePage`, `WebSite`, `Person` (должность, город, навыки, ссылки).
- `llms.txt` — короткая сводка для ИИ-ассистентов.

## Доступность

Контраст текста — уровень AA по WCAG 2.1 (на нём основан ГОСТ Р 52872-2019): текст лежит на плотных
стеклянных панелях, соотношения считаются для худшего фона (`npm run contrast`). Шрифты: заголовки —
Ubuntu, текст — Roboto, игровой интерфейс (вкладки, часы, XP, подписи, даты, цифры) — Tektur;
все три лежат в `src/app/fonts/` (латиница + кириллица), минимальный размер 14px. Видимый фокус, переход к содержанию, `lang="ru"`,
управление с клавиатуры (← → листают страницы, Alt — ведьмачье чутьё),
`prefers-reduced-motion` отключает анимации.
